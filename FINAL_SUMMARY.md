## 🆘 Quick Troubleshooting

**Q: Development server not starting?**
A: Clear node_modules and reinstall:

```bash
rm -rf node_modules package-lock.json
npm install
npm run dev
```

**Q: Styles not applying?**
A: Restart dev server - it should pick up Tailwind changes.

**Q: Images not loading?**
A: Check image URLs in data files and replace with your URLs.

**Q: Form not working?**
A: Connect to Formspree, EmailJS, or your backend API.
